# 常见问题解答（FAQ）

## 安装与启动

### Q1：macOS 打开应用提示"无法验证开发者"或"已损坏，无法打开"
**A**：开源软件未做 Apple 代码签名，这是正常现象。任选一种解决：
1. 右键点击应用图标 → **打开** → 弹窗中点 **仍要打开**
2. 终端执行：`sudo xattr -rd com.apple.quarantine '/Applications/WeChat Trade Assistant.app'`

### Q2：Windows 安装时 SmartScreen 提示"已保护你的电脑"
**A**：点击 **更多信息** → **仍要运行** 即可。同样是未签名导致，应用本身安全。

### Q3：应用启动后一直显示"正在连接后端…"卡住
**A**：后端 Python 进程启动失败。请尝试：
1. 完全退出应用（macOS: Cmd+Q；Windows: 任务管理器结束进程）
2. 重新启动
3. 若仍失败，可能是杀毒软件拦截了后端可执行文件，把应用加入白名单

### Q4：应用提示"未检测到微信"
**A**：
1. 确认已安装微信客户端并**登录**（仅安装不够，必须登录过一次产生数据库）
2. macOS：微信需安装在 `/Applications/WeChat.app` 默认路径
3. 重启本应用重新检测

## 解密相关

### Q5：macOS 首次解密失败，提示"无法读取微信内存"
**A**：macOS 系统安全限制，需先对微信做 ad-hoc 重签名：
1. 打开终端，执行：`sudo codesign --force --deep --sign - /Applications/WeChat.app`
2. 输入开机密码（输入时不可见，正常现象）
3. 看到 `replacing existing signature` 即成功
4. 重启微信重新登录，再回到本应用点击"开始首次解密"

> 应用内 **设置** 页提供"一键重签名"按钮，会自动打开终端并填好命令，你只需回车并输密码。

### Q6：Windows 首次解密失败，提示"权限不足"
**A**：读取微信进程内存需要管理员权限。
- 右键应用图标 → **以管理员身份运行**
- 首次解密完成后，日常使用从本地库读取，无需再以管理员身份运行

### Q7：微信更新后，应用又无法解密了
**A**：微信更新会覆盖已签名的二进制。
- macOS：重新执行一次 Q5 的重签名命令
- Windows：重新以管理员身份运行一次首次解密

### Q8：解密很慢，正常吗？
**A**：首次解密需处理全部历史聊天记录，时间与聊天数据量正相关，通常 1–10 分钟。语音消息的转录会更慢（每条语音约 2–5 秒）。后续使用从本地库读取，无需重复解密。

### Q9：解密后聊天记录不完整，某些客户的消息没显示
**A**：可能原因：
1. 该客户在微信里是**企业微信**联系人，而当前解密模式只处理了个人微信 → 在设置里切换解密目标
2. 消息时间早于微信本地保留的最早记录（微信会自动清理很旧的消息）
3. 该聊天是群聊 → 当前版本聚焦单聊，群聊支持在路线图中

## 语音转录

### Q10：语音消息只显示"[语音]"，没有转录文字
**A**：
1. 首次解密后，语音转录在后台批量进行，请等待几分钟
2. 若某条语音长期未转录，可在聊天记录页点击该语音手动触发
3. 确认 `models/whisper/ggml-small.bin` 模型文件存在（应用打包时已内置；若缺失会降级到占位实现）

### Q11：西班牙语转录不准确
**A**：
1. 确认使用的是 `ggml-small.bin`（多语种）而非 `ggml-tiny.bin`（轻量但准确率低）
2. 语音本身嘈杂或客户带口音会影响准确率
3. 可在设置里配置云端 LLM API，对转录文本做二次纠错（可选）

### Q12：转录会联网吗？语音内容会上传吗？
**A**：**不会**。whisper.cpp 完全在本地 CPU 上运行，语音数据不离开你的电脑。

## 意图识别与待办

### Q13：意图识别不准确，把询价识别成了下单
**A**：
1. 默认使用规则引擎（本地、快速），对中西混合语句的边界判断有限
2. 在设置里配置云端 LLM API（如 DeepSeek），可显著提升意图理解准确率
3. 也可在客户意图页手动修正某条消息的意图标签

### Q14：待办没有自动提取出来
**A**：待办提取依赖明确的动作词（报价/发货/付款/会议…）和时间词（明天/周四/下周…）。若客户表达模糊（如"之后再说"），可能不会提取。可在待办页手动添加。

### Q15：待办时间识别错了（比如"周五"识别成本周而非下周）
**A**：应用默认"周五"=最近的未来周五。若当天就是周五，则理解为下周五。如需调整，手动编辑待办的截止时间即可。

## 智能助手（MCP 自然语言查询）

### Q16：智能助手查不到任何聊天记录
**A**：可能原因：
1. **时间范围表述不匹配**：试试更明确的表述，如"上周""最近7天""2026年6月"
2. **客户名拼写不一致**：用客户在微信里的备注名或昵称（如"Juan"而非"胡安"）
3. **本地库为空**：先完成首次解密
4. 应用对跨语言查询做了降级处理：若中文关键词未命中西语消息，会自动回退到"该客户该时段的全部消息"

### Q17：智能助手的回复是列表，不像 AI 对话
**A**：未配置云端 API 时，应用返回结构化本地摘要（列出匹配消息+意图统计）。在 **设置 → API Key 配置** 填入 DeepSeek/OpenAI 兼容 API 后，回复会变成自然语言段落。

### Q18：智能助手查询很慢（超过 10 秒）
**A**：
- 简单条件查询（单客户+时间）应 < 3 秒
- 复杂分析（多客户对比+长时间范围）可能 5–10 秒
- 若配置了云端 LLM，还会加上 LLM 响应时间
- 若持续很慢，检查本地库是否过大（可考虑清理很旧的数据）

### Q19：语音输入不识别
**A**：语音输入调用本地 whisper 转录。请确认：
1. 已授予应用麦克风权限（macOS: 系统设置 → 隐私与安全 → 麦克风）
2. 对着麦克风清晰说话
3. 也可直接用文字输入查询

### Q20：配置了 API Key 后，我的聊天记录会上传到云端吗？
**A**：**原始聊天记录不会上传**。仅当你使用智能助手提问时，应用会把**检索后的小片段**（最多 40 条相关消息）发送给你配置的 LLM 以生成自然语言回复。其他功能（解密、转录、意图识别、待办提取）完全在本地，不涉及 API。清除 API Key 后立即恢复纯本地模式。

## 性能与数据

### Q21：应用占用磁盘空间很大
**A**：本地库会随聊天记录增长。可定期：
1. 在设置里清理超过 N 天的旧数据
2. 或导出后清空本地库重新解密

### Q22：换电脑怎么迁移数据？
**A**：复制本地数据库文件到新电脑的应用数据目录：
- macOS：`~/Library/Application Support/WeChatTradeAssistant/local.db`
- Windows：`%APPDATA%/WeChatTradeAssistant/local.db`

### Q23：应用会读取我的微信并导致封号吗？
**A**：应用采用**本地库优先**策略：
- 仅在首次解密和主动同步时读取微信数据库文件（只读，不修改）
- 关闭"实时解析"后完全不访问微信
- 不模拟微信协议、不自动发消息，封号风险极低
- 建议关闭实时解析，按需手动同步，进一步降低风险

## 其他

### Q24：支持群聊吗？
**A**：当前版本聚焦单聊（外贸场景以一对一沟通为主）。群聊解析在路线图中。

### Q25：支持英语客户吗？
**A**：支持。意图识别和待办提取规则已覆盖中西英三语；whisper 模型支持 99 种语言含英语。

### Q26：应用开源吗？在哪里获取源码？
**A**：开源，MIT 协议。源码与打包脚本见项目仓库。

### Q27：遇到 bug 怎么反馈？
**A**：在项目仓库提 Issue，附上：
1. 操作系统版本
2. 微信版本
3. 复现步骤
4. 应用日志（设置页可导出，日志不含聊天内容）
