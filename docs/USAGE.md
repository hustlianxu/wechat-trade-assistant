# 简易使用手册 · 南美外贸微信智能助手

本手册面向无技术背景的外贸从业者，按步骤指导你完成安装、首次配置与日常使用。

---

## 一、安装

### macOS

1. 双击下载的 `WeChat Trade Assistant-<版本>-arm64.dmg`（Apple Silicon）或 `-x64.dmg`（Intel Mac）
2. 在弹出的窗口中，把 **WeChat Trade Assistant** 图标拖到右侧的 **Applications** 文件夹
3. 打开「启动台」→ 找到 **WeChat Trade Assistant** → 右键 → **打开** → 在弹窗中点 **打开**

> **首次打开若提示"无法验证开发者"**：这是正常现象（开源软件未签名）。
> 解决：右键点击应用图标 → **打开** → **仍要打开**；
> 或在终端执行（替换为实际安装路径）：
> ```
> sudo xattr -rd com.apple.quarantine '/Applications/WeChat Trade Assistant.app'
> ```

### Windows

1. 双击下载的 `WeChat Trade Assistant Setup <版本>.exe`
2. 若 SmartScreen 提示"已保护你的电脑"，点击 **更多信息** → **仍要运行**
3. 按安装向导完成安装（可自定义安装目录）
4. 从开始菜单启动 **WeChat Trade Assistant**

## 二、首次启动配置

应用首次启动时会自动检测本机微信并引导你完成必要设置。

### 1. 微信版本检测

应用启动后进入 **设置** 页，会自动显示检测到的微信版本号。

- 若显示 **微信 4.0.x** 或 **3.9.x**：说明检测成功，可继续下一步
- 若显示 **未检测到微信**：请先安装并登录微信客户端，再重启本应用

### 2. macOS 用户：重签名微信（仅一次）

由于 macOS 系统安全限制（SIP + Hardened Runtime），需要对本机微信做一次 ad-hoc 重签名，应用才能读取微信进程内存来解密数据库。

**操作方式**（应用内提供一键引导按钮，也可手动执行）：

1. 打开 **终端**（Launchpad → 其他 → 终端）
2. 复制粘贴以下命令并回车（会要求输入开机密码，输入时不可见，输完回车即可）：
   ```
   sudo codesign --force --deep --sign - /Applications/WeChat.app
   ```
3. 看到 `/Applications/WeChat.app: replacing existing signature` 即成功
4. 重启微信，重新登录

> 此操作不会影响微信正常使用，只是让本应用有权限读取其内存。
> 微信更新后需重新执行一次。

### 3. Windows 用户：管理员权限

Windows 首次解密需要管理员权限读取微信进程内存：

- **首次解密时**：应用会弹窗提示，点击 **"以管理员身份运行"** 按钮重启应用
- 或：右键应用图标 → **以管理员身份运行**（仅首次需要，后续从本地库读取无需管理员）

### 4. 首次解密

1. 在 **设置** 页点击 **"开始首次解密"**
2. 等待进度条完成（首次需解密全部历史聊天记录，时间取决于聊天数据量，通常 1–10 分钟）
3. 完成后底部状态栏显示 **"本地库已就绪"**，即可使用全部功能

## 三、日常使用

### 1. 首页 / 仪表盘

启动后默认进入仪表盘，一目了然看到：
- **今日待办**：今天到期或逾期的待办事项
- **未读意图**：最近被识别出关键意图（询价/下单/投诉等）但尚未处理的消息
- **客户动态**：近期活跃客户的简报

### 2. 聊天记录

- 左侧为客户列表，点击任一客户查看其聊天记录
- 顶部可按 **时间范围**（今天/昨天/本周/上周/自定义）和 **关键词** 筛选
- 文字消息直接显示；**语音消息**会显示西班牙语转录文本；**图片**显示缩略图
- 右上角 **"实时解析"** 开关：开启后自动同步新消息；关闭则仅查看历史数据

### 3. 客户意图

- **客户列表页**：每个客户名后显示其最新意图标签（如 `询价` `下单` `投诉` `物流`）
- 可按意图类别筛选客户（例如只看"投诉"客户）
- 点击客户进入详情页，查看该客户所有消息及逐条意图标签

### 4. 待办事项

- 应用自动从聊天中提取待办（如客户说"明天发货""周四报价"会自动生成待办）
- **列表页**：按时间/状态/客户排序，支持手动编辑、标记完成、删除
- **汇总页**：统计各状态数量、按客户汇总，便于跟进

待办状态：`待处理` → `进行中` → `已完成` / `已取消`

### 5. 智能助手（核心功能）

底部或侧边栏点击 **"智能助手"** 进入对话界面，用自然语言提问即可，无需手动筛选。

**支持的问法示例：**

| 你想做的事 | 直接这样问 |
|------|------|
| 总结某客户某时段的沟通 | "帮我查一下上周和 Juan 的聊天，总结一下他的订单需求" |
| 对比两个客户 | "对比 Maria 和 Carlos 最近一个月关于价格的讨论" |
| 列出待办 | "把昨天所有未处理的待办列出来" |
| 查询特定话题 | "Juan 上周聊了什么" |
| 查报价历史 | "Pedro 这个月问过哪些产品的报价？" |

**输入方式**：
- **文字**：直接在对话框输入，回车发送
- **语音**：点击麦克风图标说话，应用自动转录为文字后查询（调用本地语音识别）

**返回结果**：
- 以卡片/列表形式展示匹配的聊天记录，可点击跳转到原始消息
- 上方显示 AI 摘要（配置了云端 API 时更自然；未配置时为本地结构化摘要）

> 未配置云端 API 时，应用仍支持完整检索功能，只是回复为结构化文本而非自然语言段落。

### 6. 设置

- **微信版本**：显示当前检测到的版本
- **实时解析**：开关，控制是否自动同步新消息
- **API Key 配置**（可选）：填入 DeepSeek / OpenAI 兼容 API，启用更精准的意图理解与自然语言回复
  - API 地址：如 `https://api.deepseek.com`（不带末尾斜杠）
  - API Key：你的密钥
  - 模型名：如 `deepseek-chat`
- **数据库密码**（可选）：为本地数据库设置访问密码

## 四、常见操作小贴士

1. **微信更新后无法解密**：macOS 需重新执行重签名命令；Windows 需重新以管理员身份运行一次首次解密
2. **语音消息没有转录文本**：首次解密后语音转录在后台批量进行，请耐心等待；也可在聊天记录页手动触发某条语音的转录
3. **想减少对微信的读取**：关闭"实时解析"开关，仅在你主动点击"同步新消息"时才读取微信库
4. **换电脑迁移数据**：把旧电脑上的本地数据库文件复制到新电脑的应用数据目录即可
   - macOS：`~/Library/Application Support/WeChatTradeAssistant/local.db`
   - Windows：`%APPDATA%/WeChatTradeAssistant/local.db`

## 五、数据安全说明

- 所有聊天记录、转录文本、意图数据**只存在你的电脑本地**，应用不会上传任何原始数据到外部服务器
- 仅当你主动配置云端 API Key 后，**检索后的片段**（非全量原始记录）会发送给你指定的 LLM 服务以生成更自然的回复
- 你可以随时在设置页清除 API Key，立即恢复纯本地模式
- 可用网络监控工具（如 macOS 的 Little Snitch、Windows 的防火墙日志）验证：除你配置的 LLM API 外，应用无任何对外网络请求
